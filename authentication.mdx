## Overview

TradeBotX uses **Upstox V2 and V3 APIs** as its exclusive source of live Indian market data. All market-data features — live prices, candles, intraday data, and real-time streaming — go through Upstox.

| File | Responsibility |
|---|---|
| `upstox_auth.py` | OAuth 2.0 token management |
| `upstox_client.py` | REST API wrapper for market data |
| `upstox_ws.py` | WebSocket feed for real-time ticks |

## Authentication

Upstox uses **OAuth 2.0 with a daily-expiring JWT**. Tokens expire at **midnight IST** every day.

<Steps>
  <Step title="Open the login URL" icon="external-link" title-type="p">
    Navigate to `http://localhost:8000/api/upstox/login`. TradeBotX generates the Upstox OAuth authorization URL and redirects you there.
  </Step>
  <Step title="Authorize in Upstox" icon="lock" title-type="p">
    Log in to your Upstox account and click **Authorize**. Upstox redirects you back to the callback URL.
  </Step>
  <Step title="Token saved automatically" icon="save" title-type="p">
    The callback handler exchanges the authorization code for a JWT and saves it to your `.env`. No server restart needed.
  </Step>
</Steps>

<Callout kind="alert">
  Tokens expire at **midnight IST** daily. If you see `401 Unauthorized` errors, run the login flow again at `http://localhost:8000/api/upstox/login`.
</Callout>

```bash
# Using the token in direct API calls
curl https://api.upstox.com/v2/user/profile \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Accept: application/json"
```

## REST API Endpoints Used

| Upstox Endpoint | TradeBotX Usage | Version |
|---|---|---|
| `GET /v2/market-quote/ltp` | Batch live prices for 48 stocks in one call | V2 |
| `GET /v2/market-quote/quotes` | Full OHLCV + market depth for a single stock | V2 |
| `GET /v3/historical-candle/{key}/{unit}/{interval}` | 100-day daily OHLCV for indicators | V3 |
| `GET /v3/intraday-candle/{key}/{unit}/{interval}` | Today's 5-min candles for VWAP | V3 |
| `GET /v2/user/profile` | Token validation on startup | V2 |
| `GET /v2/instruments/search` | Symbol-to-ISIN lookup | V2 |
| `wss://api.upstox.com/v3/feed` | Real-time WebSocket tick streaming | V3 WS |

### Batch LTP — Most Common Operation

All 48 NIFTY 50 prices are fetched in a **single API call**, keeping rate-limit usage minimal:

```bash
GET http://localhost:8000/api/upstox/ltp/batch?index=NIFTY50

# Response
{
  "prices": {
    "RELIANCE": 2945.50,
    "TCS": 3812.00,
    "HDFCBANK": 1680.25
  },
  "timestamp": "2025-01-15T10:30:00+05:30"
}
```

## WebSocket Feed

`upstox_ws.py` maintains a persistent WebSocket connection to the Upstox V3 feed.

| Feature | Detail |
|---|---|
| **Feed modes** | `LTPC` (last price + change) or `Full` (OHLCV + depth + OI) |
| **Auto-reconnect** | Reconnects with exponential backoff on disconnect |
| **Subscriptions** | Up to 1,000 instrument keys per connection |
| **Data format** | Protobuf, decoded to JSON by the client |

<Callout kind="info">
  The WebSocket feed activates only when the auto-scanner is running or when the Paper Trading view has live updates enabled. It is not connected on startup by default.
</Callout>

## Instrument Key Format

Upstox identifies each stock with an **instrument key**:

```
{EXCHANGE_SEGMENT}|{ISIN}
```

| Example | Stock |
|---|---|
| `NSE_EQ\|INE002A01018` | Reliance Industries |
| `NSE_EQ\|INE009A01021` | Infosys |

TradeBotX maintains hardcoded mappings in `upstox_client.py` for:
- **NIFTY 50** — 48 instruments
- **NIFTY BANK** — 12 instruments

<Callout kind="alert">
  ISINs can change after corporate actions (splits, bonus issues, demergers). If a stock returns `404`, update its mapping in `upstox_client.py` with the current ISIN from nseindia.com.
</Callout>

## Rate Limits

| Limit Type | Value |
|---|---|
| Requests per second | 25 |
| Historical candle requests per day | 1,000 |
| Intraday candle requests per day | 1,000 |

TradeBotX reduces rate-limit impact through batch LTP calls, on-demand signal computation, and a 60-second in-memory signal cache.

## Sandbox vs. Live Mode

```env
UPSTOX_MODE=live      # Real market data — daily token required
UPSTOX_MODE=sandbox   # Simulated data — suitable for development
```
