### Bugs Fixed on Day 1

<Expandable title="Bug #1 — BUY code in wrong branch (CRITICAL)" icon="alert-triangle">
  **File:** `signal_scanner.py`  
  **Symptom:** 22 scans, 0 trades despite valid scores (0.60–0.62)

  The BUY execution code was accidentally placed inside the `elif` branch (runs when conditions *don't* match) instead of the `if` branch. This meant the bot would **never trade**.

  ```python
  # BROKEN — buy code in elif (never executed):
  if score >= buy_threshold and conditions_met:
      continue  # no buy here!
  elif score >= buy_threshold:
      paper_trader.enter_trade(...)  # ← unreachable

  # FIXED — buy code in correct if branch:
  if score >= buy_threshold and conditions_met:
      paper_trader.enter_trade(...)  # ← correct
  elif score >= buy_threshold:
      logger.info("SKIP: %s", ", ".join(reasons))
  ```

  **Fix verified:** First trade (TATACONSUM) executed within minutes.
</Expandable>

<Expandable title="Bug #2 — Profit factor crash on null avg_win (HIGH)" icon="alert-triangle">
  **File:** `paper_trader.py:678`  
  **Symptom:** `/api/paper/performance` returns HTTP 500 when only losses exist

  After BAJFINANCE closed at a loss (the only closed trade), `avg_win` was `None` from the SQL query. The code divided `None / avg_loss` → `TypeError`.

  ```python
  # BROKEN:
  "profit_factor": round(abs(avg_win / avg_loss), 2) if avg_loss != 0 else None
  # avg_win could be None even when avg_loss is valid

  # FIXED:
  "profit_factor": round(abs(avg_win / avg_loss), 2)
      if (avg_win is not None and avg_loss is not None and avg_loss != 0) else None
  ```

  Now works correctly with: only losses, only wins, mixed, or no trades.
</Expandable>

<Expandable title="Bug #3 — Staggered force-close never triggered (HIGH)" icon="alert-triangle">
  **File:** `signal_scanner.py:521`  
  **Symptom:** 3 positions still open at 4:24 PM (should have closed at 15:18–15:20)

  The code compared `current_time in STAGGERED_CLOSE_TIMES` which requires an **exact match including seconds**. Scans run at :31, :32, :33 seconds — never exactly :00.

  ```python
  # BROKEN — time(15,19,32) != time(15,19,0):
  if current_time in [time(15,18), time(15,19), time(15,20)]:
      close_positions()

  # FIXED — hour:minute matching + past-close fallback:
  current_hm = (now.hour, now.minute)
  close_minutes = [(t.hour, t.minute) for t in STAGGERED_CLOSE_TIMES]

  if current_hm in close_minutes or current_hm >= close_minutes[-1]:
      close_positions()
  ```

  **Impact:** From Day 2 onwards, positions close automatically at 15:18–15:20.
</Expandable>

## Lessons Learned (Day 1)

1. **Don't modify code during market hours.** Every file save triggers `uvicorn --reload`, resetting scanner state and interrupting active scans. Make all changes before 09:30 or after 15:30.

2. **Phase 0 needs actual trades.** A conservative threshold that produces 0 trades gives no data. Lower the threshold until 2–4 trades/day happen, then tune up from there.

3. **`top_scores` logging is essential.** Without tracking the top 5 scores per scan, you can't diagnose why the bot isn't trading. Always check `scanner_log.json` if no trades appear after 30 minutes.

4. **Time comparisons need minute-level matching.** `time(15,19,32) != time(15,19,0)` — scans don't fire at exactly :00 seconds. Always compare `(hour, minute)` tuples for schedule logic.

5. **Risk management worked.** BAJFINANCE's trailing stop limited a loss to -₹32.55 instead of letting it grow. The circuit breaker is doing its job.

## Troubleshooting

| Issue | Solution |
|---|---|
| Scanner not starting | Re-do Upstox OAuth — token likely expired. Run `python api_server.py` and check logs. |
| No trades after 30 min | Check `top_scores` in `scanner_log.json`. If scores < threshold, lower `buy_score_threshold` in `config.json`. |
| API returns 500 | Check terminal logs. Fixed Bug #2 means this should no longer happen on performance endpoint. |
| Positions open after 15:20 | Bug #3 fixed — should auto-close. If still open, run `python view_db.py` to inspect, then close manually. |
| Win rate 0% | Check if losses are real (signal reversals) or admin (manual closes, slippage). Day 1 had 3 admin losses. |
| `uvicorn --reload` mid-day | Expected if you saved a file. Restart scanner: click "Start Bot" in dashboard. |
