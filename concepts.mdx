## The Four Layers

TradeBotX is split into four layers that communicate through well-defined interfaces:

| Layer | Technology | Responsibility |
|---|---|---|
| **Frontend** | React + Vite + TypeScript | Dashboard UI, SSE consumption, user interactions |
| **Backend** | FastAPI + Python | REST API gateway, business logic, scheduling |
| **Market Data** | Upstox V2/V3 API | Live prices, candles, WebSocket tick feed |
| **AI Pipeline** | LangGraph + LLMs | 13-agent analysis and decision engine |

## Frontend Components

The React app has six top-level views, each corresponding to a navigation tab:

| Component | View | Purpose |
|---|---|---|
| `ScreenerView.tsx` | Screener | NSE index screener with flag indicators |
| `AnalysisView.tsx` | Analysis | Live agent pipeline progress and results |
| `PaperTradingView.tsx` | Paper Trading | Live prices, signal table, portfolio, trade history |
| `WatchlistPanel.tsx` | Watchlist | Custom ticker list and batch analysis launcher |
| `PredictionsView.tsx` | Predictions | AI decision accuracy tracking dashboard |
| `ResultsView.tsx` | Results | Historical analysis results browser |

Supporting files: `App.tsx` (routing, SSE management), `TopNav.tsx` (6-tab navbar), `SchedulerCard.tsx` (morning scheduler UI), `types.ts` (shared TypeScript interfaces), `index.css` (dark theme design system, ~65 KB).

## AI Agent Framework

```
tradingagents/
├── agents/          Individual agent implementations
├── graph/           LangGraph workflow — connects all 13 agents
├── dataflows/       Data vendor routing (yFinance, Alpha Vantage, NSE API)
├── llm_clients/     LLM abstraction (OpenAI, Anthropic, Ollama, OpenRouter)
└── default_config.py  Pipeline settings: model names, debate rounds, vendors
```

## How a Signal Request Works

<Steps>
  <Step title="User requests a signal" icon="mouse-pointer" title-type="p">
    Frontend sends `GET /api/upstox/signals/{symbol}` to the FastAPI backend.
  </Step>
  <Step title="Backend fetches candles" icon="download" title-type="p">
    Two Upstox calls are made: 100-day daily candles and today's 5-minute intraday candles.
  </Step>
  <Step title="Technical engine runs" icon="cpu" title-type="p">
    `technical.py` computes RSI, MACD, EMA, VWAP, Bollinger Bands, Volume Surge, and Intraday Momentum.
  </Step>
  <Step title="Score returned to UI" icon="check-circle" title-type="p">
    A weighted composite score (0.0–1.0) plus all individual indicator values are returned to the frontend.
  </Step>
</Steps>

## How an AI Analysis Works

<Steps>
  <Step title="User clicks Analyse" icon="play" title-type="p">
    Frontend opens a Server-Sent Events (SSE) connection to `GET /api/analyze/stream`.
  </Step>
  <Step title="13-agent pipeline starts" icon="cpu" title-type="p">
    LangGraph runs the pipeline and emits progress events back to the frontend as each agent completes.
  </Step>
  <Step title="Agents complete their phases" icon="layers" title-type="p">
    Five analysts → bull/bear debate → trader proposal → three risk analysts evaluate the plan.
  </Step>
  <Step title="Portfolio Manager delivers verdict" icon="flag" title-type="p">
    Final BUY / SELL / HOLD decision with confidence rating is saved to SQLite and displayed in the UI.
  </Step>
</Steps>
