## The Five Layers

TradeBotX is built as five interconnected layers that communicate through well-defined interfaces:

| Layer | Technology | Responsibility |
|---|---|---|
| **Frontend** | React 19 + TypeScript + Vite | Dashboard UI, SSE consumption, REST polling |
| **API Server** | FastAPI + Python at :8000 | REST gateway, business logic, lifespan scheduling |
| **Fast Layer** | `technical.py` (pure math) | 9 deterministic indicators, signal scoring < 1 sec |
| **LLM Pipeline** | LangGraph + 13 agents | Deep research: news, fundamentals, risk debate |
| **Paper Trader + Scanner** | `paper_trader.py` + `signal_scanner.py` | Virtual portfolio, risk enforcement, auto-trading |

## Two Modes of Operation

TradeBotX runs in two distinct modes simultaneously:

<Columns cols={2}>
  <Card title="Research Mode (On-Demand)" icon="cpu">

## Backend Modules

Each Python file has a single focused responsibility:

<Columns cols={2}>
  <Card title="api_server.py" icon="server">
    FastAPI gateway — all 15 REST endpoints, SSE streaming, CORS, lifespan management. Starts scheduler and auto-scanner on boot. Thread-safe with RLock on global state. 1,000+ lines.
  </Card>
  <Card title="technical.py" icon="bar-chart-2">
    9 deterministic indicators: RSI, MACD, EMA-20/50, VWAP, Bollinger Bands, Stochastic, ATR, Volume Surge, Momentum. Dual-timeframe (daily + 5-min intraday). Returns scores 0–100. 500+ lines.
  </Card>
  <Card title="paper_trader.py" icon="dollar-sign">
    Virtual portfolio with real Upstox prices. Risk rules: 2% daily loss limit, 5% max position, mandatory SL, max 3 concurrent positions. SQLite persistence. Thread-safe with RLock. 800+ lines.
  </Card>
  <Card title="signal_scanner.py" icon="scan">
    Auto-trading bot. Runs every 5 min during market hours (09:30–15:20 IST). Batch LTP → filter movers → score signals → auto-enter/exit. Caches candles with 60-min TTL. 600+ lines.
  </Card>
  <Card title="scheduler.py" icon="clock">
    APScheduler background jobs: pre-market scan at 08:30 IST, intraday scanner every 5 min, portfolio update every 5 min. Respects NSE holiday calendar. 300+ lines.

  <Card title="database.py" icon="database">
    SQLite ORM for predictions table. Stores: ticker, decision, entry price, current price, return %, outcome, ratings. Computes win rate and Sharpe analytics. 500+ lines.

## LLM Pipeline — Phase Structure

```
Phase 1 — Analyst Team (run in parallel)
  ├── Market Analyst       Price action, trend, support/resistance
  ├── Social Media Analyst Sentiment from Twitter, Reddit, StockTwits
  ├── News Analyst         Recent news headlines and impact
  ├── Fundamentals Analyst P/E, revenue, earnings, debt ratios
  └── India Macro Analyst  RBI policy, FII/DII flows, INR/USD

Phase 2 — Researcher Team (configurable debate rounds)
  ├── Bull Researcher      Best-case scenario argument
  ├── Bear Researcher      Worst-case scenario argument
  └── Research Manager     Deep synthesis of both cases

Phase 3 — Trader
  └── Composes all analyst reports into an investment plan

Phase 4 — Risk Management Team (configurable debate rounds)
  ├── Aggressive Debater   "Increase position size"
  ├── Conservative Debater Applies SEBI margin rules, circuit limits
  ├── Neutral Debater      Balanced risk-reward view
  └── Portfolio Manager    FINAL decision: BUY/SELL/HOLD with rating
```

**Entry point:** `TradingAgentsGraph` in `tradingagents/graph/trading_graph.py`. Call `.propagate(ticker, date)` to run analysis.

## Thread Safety

Critical sections use `threading.RLock()` to prevent race conditions:

| Lock | Location | Protects |
|---|---|---|
| `_state_lock` | `api_server.py` | Global Upstox client + paper trader + scanner state |
| `_db_lock` | `paper_trader.py` | All SQLite read/write operations |
| `_scanner_lock` | `signal_scanner.py` | Signal calculation + candle cache |

**Lock acquisition order:** always `_state_lock` → `_db_lock` → `_scanner_lock`. Never reverse this order.

## How an Analysis Request Works

<Steps>
  <Step title="User clicks Analyse" icon="play" title-type="p">
    Frontend opens an SSE connection to `GET /api/analyze/stream?ticker=INFY.NS&date=2026-05-03`.
  </Step>
  <Step title="Phase 1 analysts run in parallel" icon="users" title-type="p">
    Market, News, Social Media, Fundamentals, and India Macro analysts fetch data from their respective sources and write reports to the shared `AgentState`.
  </Step>
  <Step title="Phase 2 researchers debate" icon="message-square" title-type="p">
    Bull and Bear researchers argue their cases; the Research Manager synthesises them into a consensus view.
  </Step>
  <Step title="Phase 3 trader plans" icon="trending-up" title-type="p">
    The Trader agent reads all analyst reports and produces an entry/exit plan.
  </Step>
  <Step title="Phase 4 risk team votes" icon="shield" title-type="p">
    Three risk debaters evaluate the plan; the Portfolio Manager delivers the final BUY / SELL / HOLD with a 1–5 star rating.
  </Step>
  <Step title="Result saved and streamed" icon="check-circle" title-type="p">
    The decision is saved to `predictions` table in SQLite and the final SSE event is sent to the frontend with all 13 agent reports.
  </Step>
</Steps>

## How the Auto-Scanner Works

<Steps>
  <Step title="APScheduler triggers every 5 min" icon="clock" title-type="p">
    `scheduler.py` fires the scan job during market hours (09:30–15:20 IST) on trading days only.
  </Step>
  <Step title="Batch LTP fetch" icon="download" title-type="p">
    One Upstox API call fetches live prices for all 50 NIFTY stocks simultaneously.
  </Step>
  <Step title="Signal scoring" icon="bar-chart-2" title-type="p">
    `technical.py` computes 9 indicators using cached daily candles (60-min TTL) and fresh 5-min intraday bars. Each stock gets a composite score 0–1.0.
  </Step>
  <Step title="Auto-entry" icon="trending-up" title-type="p">
    Score > 0.65 → enter paper trade (subject to risk checks: daily loss limit, position count, position size).
  </Step>
  <Step title="Auto-exit" icon="trending-down" title-type="p">
    Score < 0.35, SL hit, TP hit, trailing stop triggered, or 15:20 IST → exit position. Log reason to SQLite.
  </Step>
</Steps>

## Indian Market Specifics

- Tickers use `.NS` (NSE) suffixes, auto-appended in `tradingagents/utils/agent_utils.py`
- NSE index constituent lists (Nifty 50, Bank Nifty, IT, Pharma, Auto) are hardcoded in `tradingagents/dataflows/nse_api.py`
- India Macro Analyst covers RBI policy, FII/DII flows, INR/USD exchange rate
- Conservative Debater applies SEBI margin rules and circuit breaker limits
- NSE holiday calendar enforced via `nse_holidays.py` (Mahashivratri, Holi, Diwali, etc.)
- Market hours: **09:30–15:20 IST**, Monday–Friday (excluding NSE holidays)
