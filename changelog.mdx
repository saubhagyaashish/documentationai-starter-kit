## Known Limitations

These are the current constraints to be aware of:

| Limitation | Impact | Workaround |
|---|---|---|
| **Daily token expiry** | Upstox tokens expire at midnight IST | Run OAuth flow each morning via dashboard "Login to Upstox" |
| **Hardcoded ISINs** | Instrument keys may go stale after corporate actions | Manually update `upstox_client.py` with current ISIN from nseindia.com |
| **Single-user** | No authentication layer — server open to local network | Run behind a firewall or on localhost only |
| **Paper trading only** | No real order execution | By design — validate strategy before Phase 14 go-live |
| **Intraday 404s** | V3 candle endpoint returns 404 when market is closed | Expected — scanner falls back to daily data |
| **LLM pipeline too slow for intraday** | 2–5 min per stock, can't react in real time | Fast technical layer (<1 sec) handles intraday; LLM used for research only |

## Honest Expectations

Before planning to deploy real capital, read this section carefully.

### What Is Grounded and Achievable

| Item | Why It's Real |
|---|---|
| Automated screener + scheduler | Pure engineering. Already done. Works today. |
| Paper trading engine | Virtual portfolio with real prices. Standard. Done. |
| Stop-loss / take-profit automation | Simple conditionals. Every algo platform does this. |
| Cloud deployment | Standard DevOps. Nothing novel. |
| Prediction tracking + accuracy dashboard | Just database + math. Done. |

### What Needs Honest Expectations

| Claim | The Reality |
|---|---|
| **"Win rate > 52%"** | After fees, slippage, and taxes, consistently beating 52% is **hard**. Most retail algo bots land at 45–55%. The edge is thin and fragile. |
| **"Sharpe > 1.0"** | Most successful retail algos sit at 0.6–1.2 Sharpe. Retail bots hitting 1.5+ consistently would outperform most hedge funds. Be realistic. |
| **"Self-improving after 100 trades"** | 100 trades is **statistically meaningless**. You need 500+ trades across different market regimes (bull, bear, sideways, high VIX) before signal weight changes are trustworthy. |
| **"FII/DII flow as intraday signal"** | FII data is published at 6 PM. The market already moved. It's a lagging indicator — useful for context, not intraday entries. |
| **"Capital doubling every 3 months"** | This implies ~100% annual return. Professional quant funds target 15–30% annually. Scale on **Sharpe stability**, not calendar dates. |
| **"Full autonomy — user is spectator"** | Even Renaissance Technologies has human oversight. Full autonomy is a goal, not a state. The bot needs a **supervisor** (you), especially in the first year. |

### Minimum Criteria to Go Live (Phase 14)

| Metric | Minimum Threshold |
|---|---|
| Win Rate | > 50% after fees and slippage |
| Sharpe Ratio | > 0.7 (> 1.0 is excellent but rare for retail) |
| Max Drawdown | < 15% |
| Profit Factor | > 1.2 |
| Total Trades | > 200 across different market conditions |
| Time Span | Must include at least one NIFTY correction (> -5%) |

### Capital Scaling Plan

| When | Capital | Condition |
|---|---|---|
| Start | ₹10,000 | Prove live mode works, find bugs |
| After Sharpe ≥ 0.7 for 3 months | ₹25,000 | Scale only if performance holds |
| After Sharpe ≥ 0.8 for 6 months | ₹50,000 | Max drawdown stayed < 12% |
| After 1 year of live profit | ₹1,00,000 | Survived at least one correction |

<Callout kind="alert">
  Scale on consistency, not on winning streaks. A bot that made 8% last month might have just been lucky. A bot that made 1.5% every month for 6 months has an edge.
</Callout>

## The Core Trading Philosophy

> **The LLM is the analyst. The rule engine is the trader. The risk manager is the adult in the room.**

- LLMs generate ideas based on news, fundamentals, and sentiment
- The fast rule engine decides whether those ideas are worth acting on (based on technical data)
- Risk rules decide how much to bet
- Stop-losses decide when to admit the bet was wrong
- Trade logs make sure we learn from every mistake so we never make the same one twice

**The hardest part isn't code — it's the waiting.** Trading is not about prediction. It's about managing the uncertainty that comes *after* you enter.
