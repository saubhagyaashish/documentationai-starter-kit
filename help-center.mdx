## Quick Answers

<Expandable title="Do I need a live Upstox trading account?" default-open="false">
  Yes, for live market data you need a funded Upstox account and a developer app. For development and testing, set `UPSTOX_MODE=sandbox` in your `.env` to use simulated data without a live account.
</Expandable>

<Expandable title="Will TradeBotX place real trades?" default-open="false">
  No. TradeBotX is designed exclusively for paper trading. It simulates trades in SQLite without sending any orders to Upstox or any exchange.
</Expandable>

<Expandable title="My Upstox token expired. What do I do?" default-open="false">
  Navigate to `http://localhost:8000/api/upstox/login` in your browser, log in to Upstox, and authorize the app. The new token is saved to `.env` automatically — no server restart needed.
</Expandable>

<Expandable title="How much does it cost to run TradeBotX?" default-open="false">
  The software itself is free and open-source. You will need an OpenAI API key (billed per token) and an Upstox developer account (free tier available). Running one AI analysis typically costs a few cents in OpenAI tokens.
</Expandable>
