## Prerequisites

| Requirement | Version | Notes |
|---|---|---|
| **Python** | 3.10+ | 3.12 recommended |
| **Node.js** | 18+ | Required for the React frontend |
| **Upstox Developer Account** | — | Free at developer.upstox.com |
| **LLM API Key** | — | At least one: OpenAI, Anthropic, Google, xAI, or OpenRouter |

<Callout kind="tip">
  Data fetching (stock prices, fundamentals, news) works out of the box via **yfinance** — no extra key needed. Upstox is required only for live prices during paper trading.
</Callout>

## Step 1 — Clone & Set Up Python Environment

```powershell
# 1. Clone the repo (skip if already done)
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents

# 2. Create a virtual environment
python -m venv venv

# 3. Activate it
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# 4. Install the package and all dependencies
pip install -e .
```

## Step 2 — Configure API Keys

Copy the example env file and fill in your keys:

```powershell
copy .env.example .env
```

Open `.env` and add your keys. At minimum you need **one LLM provider key**:

```env
# ========== LLM Providers (choose one or more) ==========
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...
XAI_API_KEY=...
OPENROUTER_API_KEY=...

# ========== Upstox (required for live paper trading) ==========
UPSTOX_API_KEY=your-api-key-here
UPSTOX_API_SECRET=your-api-secret-here
UPSTOX_REDIRECT_URI=http://localhost:8000/callback
UPSTOX_ACCESS_TOKEN=              # leave blank — filled after OAuth login
UPSTOX_MODE=live                  # "live" or "sandbox"

# ========== Optional: Data Vendors ==========
# yfinance (free) is the default. Alpha Vantage requires a paid subscription.
ALPHA_VANTAGE_API_KEY=

# ========== Debug ==========
DEBUG=false
```

<Callout kind="alert">
  Never commit `.env` to Git. It contains credentials. Add `.env` to your `.gitignore`.
</Callout>

### Getting Your Upstox Keys

<Steps>
  <Step title="Create a developer app" icon="plus" title-type="p">
    Go to [developer.upstox.com](https://developer.upstox.com/), sign in with your Upstox trading account, and create a new application named "TradeBotX".
  </Step>
  <Step title="Set the redirect URI" icon="link" title-type="p">
    In your app settings, set the **Redirect URI** to `http://localhost:8000/callback`.
  </Step>
  <Step title="Copy your credentials" icon="copy" title-type="p">
    Copy the **API Key** and **API Secret** into your `.env` file. Leave `UPSTOX_ACCESS_TOKEN` blank for now.
  </Step>
</Steps>

## Step 3 — Configure Runtime Settings

Create or update `config.json` in the project root:

```json
{
  "scanner": {
    "enabled": true,
    "interval_minutes": 5,
    "index": "NIFTY50",
    "buy_score_threshold": 0.65,
    "sell_score_threshold": 0.35,
    "max_auto_positions": 3,
    "position_size_pct": 3.0,
    "force_close_time": "15:20"
  },
  "scheduler": {
    "enabled": true,
    "pre_market_time": "08:30"
  },
  "paper_trader": {
    "initial_capital": 100000,
    "daily_loss_limit_pct": 2.0,
    "max_position_size_pct": 5.0,
    "mandatory_stop_loss_pct": 1.5
  },
  "upstox": {
    "api_key": "${UPSTOX_API_KEY}",
    "api_secret": "${UPSTOX_API_SECRET}"
  }
}
```

**Key settings to tune:**

| Setting | Default | Effect |
|---|---|---|
| `scanner.buy_score_threshold` | 0.65 | Raise (e.g. 0.75) for fewer but higher-quality trades |
| `scanner.position_size_pct` | 3.0 | % of capital per trade (3% = ~33 max positions) |
| `scanner.max_auto_positions` | 3 | Max concurrent open positions from scanner |
| `paper_trader.initial_capital` | 100000 | Starting virtual capital in ₹ |

## Step 4 — Start the Backend

<Tabs>
  <Tab title="Terminal 1 — Backend" icon="server">
    ```powershell
    # Make sure venv is active
    venv\Scripts\activate

    python api_server.py
    ```

    On successful startup you should see:
    ```
    Uvicorn running on http://localhost:8000
    Database initialised
    Upstox client initialised (live mode)
    Paper trader initialised with ₹100000 capital
    Scheduler initialised
    Auto-scanner resumed (was enabled in config)
    ```
  </Tab>
  <Tab title="Terminal 2 — Frontend" icon="monitor">
    ```powershell
    cd frontend
    npm install          # only needed the first time
    npm run dev
    ```

    Open **http://localhost:5173** in your browser.
  </Tab>
</Tabs>

<Callout kind="alert">
  Do **not** run `python main.py` to start the dashboard — that is a standalone CLI demo script that runs the 13-agent pipeline directly without a UI. Use `api_server.py` + `npm run dev` for the full dashboard experience.
</Callout>

## Step 5 — Authorize Upstox (First Run)

After starting the backend, you need to authorize Upstox once:

<Steps>
  <Step title="Open the login URL" icon="external-link" title-type="p">
    Visit **http://localhost:5173** and click **"Login to Upstox"** in the top-right corner, or navigate directly to `http://localhost:8000/callback`.
  </Step>
  <Step title="Grant permission" icon="lock" title-type="p">
    Log in to Upstox and click **Authorize**. Upstox redirects back to `http://localhost:8000/callback?code=xxx`.
  </Step>
  <Step title="Token saved automatically" icon="check-circle" title-type="p">
    The access token is saved to your `.env` file and loaded in-memory. No restart needed. Tokens expire at **midnight IST** daily and must be refreshed each morning.
  </Step>
</Steps>

## Troubleshooting

| Issue | Fix |
|---|---|
| `ModuleNotFoundError` | Activate venv: `venv\Scripts\activate` |
| `pip install -e .` fails | Update pip: `python -m pip install --upgrade pip` |
| `OPENAI_API_KEY not found` | Check `.env` file in project root |
| `Failed to connect to backend` | Ensure `python api_server.py` is running in Terminal 1 |
| `npm: command not found` | Install Node.js 18+ from nodejs.org |
| `ENOENT: no such file` in frontend | Run `npm install` inside the `frontend/` folder first |
| Frontend blank page | Check browser console (F12) for errors; restart both terminals |
| Scanner not starting | Check Upstox token in `.env`. Run `python upstox_auth.py` to refresh |
| "Database is locked" error | SQLite locking issue — restart `api_server.py` |
| Market data 15+ min old | Using yfinance (free, delayed). Upstox provides real-time data |
| `KeyboardInterrupt` in `main.py` | Normal — you pressed Ctrl+C. The pipeline was running fine |

## Common Tasks

### Change Scanner Sensitivity

Edit `config.json`:
```json
{
  "scanner": {
    "buy_score_threshold": 0.55
  }
}
```
Lower = more trades (aggressive). Higher = fewer trades (conservative).

### Pause Auto-Scanner
```bash
curl -X POST http://localhost:8000/api/scanner/stop
```

### Reset Paper Trading Capital

Delete `predictions.db` and restart `api_server.py`. A fresh database is created with ₹100,000 capital.

### View Portfolio P&L
```bash
curl http://localhost:8000/api/paper/performance
```

### Export Trade History
```bash
sqlite3 predictions.db "SELECT * FROM paper_trades;" > trades.csv
```
