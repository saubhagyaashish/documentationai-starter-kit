## Overview

TradeBotX uses **SQLite** (`predictions.db`) for all persistent storage. The file is created automatically in the project root on first run.

| Table | Stores | Used By |
|---|---|---|
| `predictions` | Every LLM analysis result with outcomes | PredictionsView accuracy dashboard |
| `paper_trades` | All auto-scanner and manual trades (open + closed) | PaperTradingView history |
| `paper_portfolio` | Current portfolio state and daily metrics | DashboardView, PaperTradingView |

**Thread-safe:** All operations wrapped in `threading.RLock()` — no race conditions, no "database is locked" errors.

---

## Table: predictions

Stores every LLM analysis result from `/api/analyze/stream`.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | Auto-increment |
| `ticker` | TEXT NOT NULL | Stock symbol (e.g., "INFY.NS") |
| `trade_date` | TEXT NOT NULL | Analysis date (YYYY-MM-DD) |
| `decision` | TEXT NOT NULL | BUY, SELL, HOLD, OVERWEIGHT, UNDERWEIGHT |
| `rating` | TEXT | LLM confidence rating (1/5 to 5/5) |
| `price_at_prediction` | REAL | Stock price when analysis ran |
| `current_price` | REAL | Latest LTP (updated periodically) |
| `return_pct` | REAL | `(current - entry) / entry × 100` |
| `is_win` | INTEGER | 1 = win, 0 = loss, NULL = pending |
| `outcome_checked_at` | TEXT | When outcome was determined |
| `created_at` | TEXT NOT NULL | ISO 8601 timestamp |

**Indexes:**
```sql
CREATE INDEX idx_predictions_ticker ON predictions(ticker);
CREATE INDEX idx_predictions_date   ON predictions(trade_date DESC);
CREATE INDEX idx_predictions_rating ON predictions(rating);
```

## Table: paper_trades

One row per trade — both open positions and completed trades.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | Auto-increment |
| `symbol` | TEXT NOT NULL | Stock symbol (e.g., "INFY.NS") |
| `direction` | TEXT NOT NULL | "BUY" or "SELL" |
| `quantity` | INTEGER NOT NULL | Number of shares |
| `entry_price` | REAL NOT NULL | Entry price |
| `exit_price` | REAL | Exit price (NULL if still open) |
| `entry_time` | TEXT NOT NULL | Entry timestamp (ISO 8601) |
| `exit_time` | TEXT | Exit timestamp (NULL if open) |
| `pnl` | REAL | P&L in rupees: `(exit - entry) × qty` |
| `pnl_pct` | REAL | P&L percentage |
| `stop_loss` | REAL NOT NULL | Stop-loss price |
| `target_price` | REAL NOT NULL | Target price |
| `exit_reason` | TEXT | SL_HIT, TARGET_HIT, TIME_STOP, MANUAL, TRAILING_STOP |
| `strategy` | TEXT | TECHNICAL_SIGNAL or MANUAL |

**Indexes:**
```sql
CREATE INDEX idx_trades_symbol_exit ON paper_trades(symbol, exit_time);
CREATE INDEX idx_trades_date_range  ON paper_trades(exit_time DESC);
```

## Table: paper_portfolio

Single-row table (id = 1) storing current portfolio state. Recalculated on every trade and every 5 minutes.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | Always 1 |
| `capital` | REAL NOT NULL | Current cash available |
| `initial_capital` | REAL NOT NULL | Starting capital (100,000) |
| `total_pnl` | REAL | All-time P&L |
| `total_pnl_pct` | REAL | All-time return % |
| `daily_pnl` | REAL | Today's P&L |
| `daily_trades` | INTEGER | Trades executed today |
| `daily_wins` | INTEGER | Wins today |
| `daily_losses` | INTEGER | Losses today |
| `total_trades` | INTEGER | All-time trade count |
| `total_wins` | INTEGER | All-time wins |
| `total_win_rate` | REAL | All-time win rate (0.0–1.0) |
| `daily_loss_limit_active` | INTEGER | 1 = circuit breaker triggered |
| `last_updated` | TEXT | When portfolio was last recalculated |

**Daily Reset:** Every morning at 08:30 IST, `daily_pnl`, `daily_trades`, `daily_wins`, `daily_losses` reset to 0. All-time metrics accumulate.

## Data Flow

### On Auto-Trade Entry

```
signal_scanner.py: score > threshold
    ↓
paper_trader.enter_trade(symbol, qty, price, SL, TP)
    ↓
Risk checks:
  • daily_pnl >= -2% * initial_capital?
  • qty * price <= 5% * capital?
  • len(open_positions) < max_auto_positions?
    ↓
INSERT INTO paper_trades (direction='BUY', ...)
UPDATE paper_portfolio: capital -= (qty * price * 1.0005)  ← 0.05% slippage
    ↓
Scanner monitors every 5 min:
  • price <= stop_loss → EXIT
  • price >= target → EXIT
  • trailing_stop triggered → EXIT
  • 15:20 IST → FORCE EXIT
```

### On Trade Exit

```
paper_trader.exit_trade(trade_id, exit_price, reason)
    ↓
pnl = (exit_price - entry_price) * qty
    ↓
UPDATE paper_trades: exit_price, exit_time, pnl, exit_reason
UPDATE paper_portfolio:
  • capital += (exit_price * qty) - fees
  • daily_pnl += pnl
  • daily_wins / daily_losses incremented
  • total_pnl += pnl, total_trades += 1
    ↓
Check circuit breaker:
  • daily_pnl < -2% * initial_capital → daily_loss_limit_active = 1
  • Active → scanner stops entering new trades (existing positions still monitored)
```

## Useful Queries

<Tabs>
  <Tab title="Portfolio Summary" icon="dollar-sign">
    ```sql
    SELECT
      capital,
      initial_capital,
      total_pnl,
      ROUND(100.0 * total_pnl / initial_capital, 2) AS roi_pct,
      total_trades,
      total_wins,
      ROUND(100.0 * total_wins / NULLIF(total_trades, 0), 1) AS win_rate,
      daily_pnl,
      daily_trades
    FROM paper_portfolio;
    ```
  </Tab>
  <Tab title="Open Positions" icon="list">
    ```sql
    SELECT
      symbol,
      quantity,
      entry_price,
      stop_loss,
      target_price,
      entry_time
    FROM paper_trades
    WHERE exit_time IS NULL
    ORDER BY entry_time DESC;
    ```
  </Tab>
  <Tab title="Win Rate by Rating" icon="percent">
    ```sql
    SELECT
      rating,
      COUNT(*) AS count,
      SUM(is_win) AS wins,
      ROUND(100.0 * AVG(is_win), 1) AS win_rate_pct,
      ROUND(AVG(return_pct), 2) AS avg_return_pct
    FROM predictions
    WHERE is_win IS NOT NULL
    GROUP BY rating
    ORDER BY rating DESC;
    ```
  </Tab>
  <Tab title="Daily P&L" icon="calendar">
    ```sql
    SELECT
      DATE(exit_time) AS trade_date,
      COUNT(*) AS trades,
      SUM(CASE WHEN pnl > 0 THEN 1 ELSE 0 END) AS wins,
      ROUND(SUM(pnl), 2) AS daily_pnl,
      ROUND(100.0 * AVG(pnl), 2) AS avg_pnl_per_trade
    FROM paper_trades
    WHERE exit_time IS NOT NULL
    GROUP BY DATE(exit_time)
    ORDER BY trade_date DESC;
    ```
  </Tab>
  <Tab title="Per-Symbol Performance" icon="trending-up">
    ```sql
    SELECT
      symbol,
      COUNT(*) AS trades,
      ROUND(SUM(pnl), 2) AS total_pnl,
      ROUND(100.0 * SUM(CASE WHEN pnl > 0 THEN 1 ELSE 0 END) / COUNT(*), 0) AS win_rate
    FROM paper_trades
    WHERE exit_time IS NOT NULL
    GROUP BY symbol
    ORDER BY total_pnl DESC;
    ```
  </Tab>
</Tabs>

## Thread Safety

All database operations wrapped with `threading.RLock()`:

```python
# paper_trader.py
self._db_lock = threading.RLock()

def enter_trade(self, symbol, qty, price, sl, tp):
    with self._db_lock:           # ← acquire lock
        conn = self._conn()
        conn.execute("INSERT INTO paper_trades ...", (...))
        conn.execute("UPDATE paper_portfolio ...", (...))
        conn.commit()
                                  # ← release lock (auto)

# api_server.py
_state_lock = threading.RLock()

@app.post("/api/paper/buy")
async def buy():
    with _state_lock:             # ← serialize all HTTP access
        paper_trader.enter_trade(...)
```

**Result:** No lost updates, no "database is locked" errors, no data corruption under concurrent access.

## Maintenance

### Backup Database
```bash
# Copy the database
cp predictions.db predictions.db.backup

# Export all trades to CSV
sqlite3 predictions.db ".mode csv" ".output trades.csv" "SELECT * FROM paper_trades;"
```

### Reset Portfolio (Start Fresh)
```bash
# Delete database — api_server.py will recreate it with fresh tables
del predictions.db

# Restart the backend
python api_server.py
```

<Callout kind="alert">
  Deleting `predictions.db` removes all prediction history and trade records permanently. Back it up first.
</Callout>

### Check Database Health
```bash
sqlite3 predictions.db "PRAGMA integrity_check;"
sqlite3 predictions.db "VACUUM;"    # Reduce file size
```
