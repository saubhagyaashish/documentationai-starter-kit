## Overview

The AI pipeline is the analytical core of TradeBotX. It is a **LangGraph-based multi-agent system** where 13 specialized agents collaborate and debate to produce a single, well-reasoned trading decision.

The pipeline runs in **five sequential phases**. Earlier phases feed context into later ones so that by the time the Portfolio Manager makes the final call, it has weighed technical charts, news sentiment, fundamentals, macro conditions, a bull/bear debate, and three risk perspectives.

<Callout kind="info">
  A full pipeline run takes approximately **2 minutes** per stock. Progress is streamed to the frontend in real time via Server-Sent Events.
</Callout>

## The Five Phases

<Steps>
  <Step title="Phase 1 — Analysis" icon="search" title-type="p">
    Five specialist analysts independently gather and interpret data. Their reports become the shared evidence base for all later agents.
  </Step>
  <Step title="Phase 2 — Research Debate" icon="message-square" title-type="p">
    A Bull Researcher and a Bear Researcher each build the strongest possible case from the analyst reports. A Research Manager mediates and produces a balanced summary.
  </Step>
  <Step title="Phase 3 — Trading Proposal" icon="trending-up" title-type="p">
    The Trader agent reads the research summary and proposes a specific plan: direction, entry price, stop-loss, and target.
  </Step>
  <Step title="Phase 4 — Risk Debate" icon="shield" title-type="p">
    Three risk analysts evaluate the trader's plan — aggressive (growth-focused), conservative (capital-preservation), and neutral (balanced).
  </Step>
  <Step title="Phase 5 — Final Decision" icon="flag" title-type="p">
    The Portfolio Manager reads all three risk views and issues the final **BUY**, **SELL**, or **HOLD** with a confidence rating.
  </Step>
</Steps>

## Agent Roster

### Phase 1 — Analysts

| Agent | Role | Data Sources |
|---|---|---|
| **Market Analyst** | Technical chart analysis — price patterns, momentum, trend | yFinance OHLCV |
| **Social Media Analyst** | Retail sentiment from social platforms | Social media APIs |
| **News Analyst** | Recent news events and their market impact | News APIs |
| **Fundamentals Analyst** | P/E ratio, revenue growth, earnings quality | Financial data APIs |
| **India Macro Analyst** | GDP, RBI policy, FII/DII flows, sector rotation | Macro data sources |

### Phase 2 — Researchers

| Agent | Role |
|---|---|
| **Bull Researcher** | Constructs the strongest possible bullish case from all five analyst reports |
| **Bear Researcher** | Constructs the strongest possible bearish case from all five analyst reports |
| **Research Manager** | Mediates the debate and synthesises a balanced summary |

### Phase 3 — Trader

| Agent | Role |
|---|---|
| **Trader** | Proposes a specific trade plan (direction, entry price, stop-loss, target) |

### Phase 4 — Risk Analysts

| Agent | Lens |
|---|---|
| **Aggressive Analyst** | Upside potential, momentum, opportunity cost |
| **Conservative Analyst** | Downside risk, position sizing, worst-case scenarios |
| **Neutral Analyst** | Risk/reward ratio, expected value, portfolio fit |

### Phase 5 — Decision Maker

| Agent | Role |
|---|---|
| **Portfolio Manager** | Issues the final BUY / SELL / HOLD with confidence rating (0.0–1.0) |

## LLM Configuration

The pipeline supports multiple providers via `tradingagents/llm_clients/`:

| Provider | Model | Notes |
|---|---|---|
| **OpenAI** | GPT-4, GPT-4o | Default — requires `OPENAI_API_KEY` |
| **Anthropic** | Claude 3.5 Sonnet | Drop-in replacement |
| **Google** | Gemini Pro | Drop-in replacement |
| **Ollama** | Any local model | Requires running Ollama locally |
| **OpenRouter** | Any hosted model | Flexible provider routing |

Set the active provider and model in `tradingagents/default_config.py`.
