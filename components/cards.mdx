## Overview

`technical.py` (500+ lines) computes 9 deterministic indicators using raw OHLCV candle data from Upstox. No external TA library — pure pandas/numpy. Scores 50 stocks in **under 1 second**.

| Score Range | Signal | Action |
|---|---|---|
| > 0.65 | **BUY** | Auto-scanner enters trade |
| 0.35 – 0.65 | **HOLD** | No action |
| < 0.35 | **SELL** | Auto-scanner exits open position |

## Dual-Timeframe Approach

| Timeframe | Data | Indicators |
|---|---|---|
| **Daily** (100 bars) | Upstox historical candles (cached 60 min) | RSI, MACD, EMA-20/50, Bollinger, Stochastic, ATR, Volume, Momentum |
| **5-min intraday** (today) | Upstox intraday candles | VWAP, intraday bias |

Entry requires both timeframes to agree: daily score > 0.65 **AND** 5-min price action is bullish. This dual confirmation reduces false signals.

## The 9 Indicators

<Tabs>
  <Tab title="RSI" icon="activity">
    **14-period Relative Strength Index** — detects overbought/oversold.

    ```
    RSI = 100 - (100 / (1 + RS))
    RS  = Avg Gain / Avg Loss over 14 periods
    ```

    | RSI Value | Points |
    |---|---|
    | < 30 (oversold) | +15 |
    | 30–50 (weak) | +5 |
    | 50–70 (normal) | +5 |
    | > 70 (overbought) | +15 |

    Applied to both daily and 5-min timeframes.
  </Tab>
  <Tab title="MACD" icon="trending-up">
    **12/26/9 MACD** — detects trend changes and momentum.

    ```
    MACD Line   = EMA(12) - EMA(26)
    Signal Line = EMA(9) of MACD Line
    Histogram   = MACD Line - Signal Line
    ```

    | Condition | Points |
    |---|---|
    | MACD > Signal (bullish cross) | +12 |
    | MACD < Signal (bearish cross) | -12 |
    | Histogram expanding | +3 |
    | Histogram contracting | -2 |
  </Tab>
  <Tab title="EMA" icon="bar-chart-2">
    **20-EMA and 50-EMA** — trend direction.

    | Condition | Points |
    |---|---|
    | Price > EMA20 > EMA50 (uptrend) | +12 |
    | Price > EMA20, EMA20 < EMA50 (mixed) | +5 |
    | Price < EMA20 < EMA50 (downtrend) | -12 |
    | EMA20 crossing above EMA50 (golden cross) | +10 |

    Also applied on 5-min bars for intraday entry confirmation.
  </Tab>
  <Tab title="VWAP" icon="percent">
    **Volume-Weighted Average Price** — institutional reference price.

    ```
    VWAP = Cumulative(Typical Price × Volume) / Cumulative(Volume)
    Typical Price = (High + Low + Close) / 3
    ```

    | Condition | Points |
    |---|---|
    | Price > VWAP (buyers in control) | +18 |
    | Price < VWAP (sellers in control) | -18 |
    | Price within 1% of VWAP | +3 bonus |

    Resets daily at 09:30 IST. Uses 5-min intraday bars only.
  </Tab>
  <Tab title="Bollinger" icon="radio">
    **20-SMA ± 2σ Bollinger Bands** — volatility extremes.

    ```
    Middle = 20-SMA
    Upper  = Middle + (2 × StdDev)
    Lower  = Middle - (2 × StdDev)
    ```

    | Condition | Points |
    |---|---|
    | Price at lower band + volume surge | +10 (bounce) |
    | Price at upper band | -8 (reversal) |
    | Band width expanding | +2 |
    | Band width contracting | -1 |
  </Tab>
  <Tab title="Stochastic" icon="sliders">
    **%K and %D** — momentum strength.

    ```
    K% = (Close - Lowest Low) / (Highest High - Lowest Low) × 100
    D% = 3-SMA of K%
    ```

    | Condition | Points |
    |---|---|
    | K% < 20, D% < 20 (very oversold) | +8 |
    | K% > 80, D% > 80 (very overbought) | -8 |
    | K% crossing above D% (bullish) | +6 |
    | K% crossing below D% (bearish) | -6 |
  </Tab>
  <Tab title="ATR" icon="maximize">
    **14-period Average True Range** — volatility measure used to set dynamic stop-losses.

    ```
    TR  = MAX(High-Low, |High-Prev Close|, |Low-Prev Close|)
    ATR = SMA(TR, 14)
    ```

    | Condition | Points |
    |---|---|
    | ATR > historical average | +3 |
    | ATR < historical average | -2 |

    **Also used for:** Dynamic stop-loss = Entry Price − (1.5 × ATR)
  </Tab>
  <Tab title="Volume" icon="bar-chart">
    **Volume Surge** (vs. 20-day average) — confirms smart money participation.

    ```
    Volume Ratio = Current Volume / 20-SMA(Volume)
    ```

    | Volume Ratio | Points |
    |---|---|
    | > 2.0× (200% above average) | +15 |
    | > 1.5× (150% above average) | +8 |
    | < 0.8× (weak volume) | -5 |

    **Veto rule:** If Volume Ratio < 1.2, the entire score returns 0 — no trade enters without volume confirmation.
  </Tab>
  <Tab title="Momentum" icon="zap">
    **Rate of Change (ROC)** over 14 days — speed of price movement.

    ```
    ROC = (Price[today] - Price[14 days ago]) / Price[14 days ago] × 100
    ```

    | ROC | Points |
    |---|---|
    | > +5% | +12 |
    | > +2% | +7 |
    | < -2% | -7 |
    | < -5% | -12 |
  </Tab>
</Tabs>

## Composite Score Formula

All 9 indicator points are summed and normalised to 0–1.0:

```python
def compute_signal_score(daily_bars, intraday_bars):
    score = 0
    score += rsi_points(daily_bars)          # 0–15
    score += macd_points(daily_bars)         # -12 to +12, normalised
    score += ema_points(daily_bars)          # -12 to +12, normalised
    score += vwap_points(intraday_bars)      # -18 to +18, normalised
    score += bollinger_points(daily_bars)    # -8 to +10, normalised
    score += stochastic_points(daily_bars)   # -8 to +8, normalised
    score += atr_points(daily_bars)          # -2 to +3, normalised
    volume = volume_points(daily_bars)       # 0 to +15
    if volume < 1.2: return 0               # VETO: no volume = no trade
    score += volume
    score += momentum_points(daily_bars)     # -12 to +12, normalised

    return min(1.0, score / 100.0)          # Normalise to 0–1.0
```

## Exit Conditions

The scanner exits a position when:
1. Score drops below 0.35 (signal reversed)
2. Price hits stop-loss (1.5% below entry, or 2× ATR)
3. Price hits take-profit (+2.5% default)
4. Trailing stop triggered (price falls 2% from high)
5. Force-close at 15:20 IST (end of intraday)
6. Daily loss limit hit (-2% of capital) — circuit breaker
