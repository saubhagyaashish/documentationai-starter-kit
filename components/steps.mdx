## Base URL

```
http://localhost:8000
```

Interactive docs are available at **http://localhost:8000/docs** (Swagger UI) and **http://localhost:8000/redoc**.

---

## Market Data

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/upstox/ltp/batch?index=NIFTY50` | Live prices for all index stocks in one call |
| `GET` | `/api/upstox/ltp/{symbol}` | Live price for a single stock |
| `GET` | `/api/upstox/quote/{symbol}` | Full OHLCV + market depth |
| `GET` | `/api/upstox/candles/{symbol}` | Historical daily candles |
| `GET` | `/api/upstox/signals/{symbol}` | Composite technical signal score |
| `GET` | `/api/upstox/movers` | Top movers by % change |
| `GET` | `/api/upstox/instruments` | All supported symbol → ISIN mappings |

## AI Analysis

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/analyze/stream` | SSE stream — live 13-agent pipeline |
| `POST` | `/api/analyze/batch` | Batch analyse multiple tickers |
| `GET` | `/api/screen` | NSE index screener with flagged stocks |
| `GET` | `/api/indices` | Available NSE indices |
| `GET` | `/api/results` | Historical analysis results |

### SSE Stream Events

```bash
curl -N "http://localhost:8000/api/analyze/stream?ticker=RELIANCE"

event: progress
data: {"agent": "market_analyst", "status": "complete", "pct": 15}

event: result
data: {"decision": "BUY", "rating": 0.78, "reports": {...}}
```

## Paper Trading

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/paper/portfolio` | Open positions, capital, daily and total P&L |
| `POST` | `/api/paper/buy` | Enter a paper trade |
| `POST` | `/api/paper/sell` | Exit a paper trade |
| `GET` | `/api/paper/history` | All closed trades |
| `GET` | `/api/paper/performance` | Win rate and P&L statistics |

---

## Auto-Scanner

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/scanner/status` | Scanner state, last scan time, last signals |
| `POST` | `/api/scanner/start` | Start the auto-trading bot |
| `POST` | `/api/scanner/stop` | Stop the auto-trading bot |
| `POST` | `/api/scanner/scan-now` | Trigger an immediate scan cycle |
| `POST` | `/api/scanner/config` | Update scanner settings |

---

## Watchlist

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/watchlist/custom` | Get the custom ticker list |
| `POST` | `/api/watchlist/custom` | Add a ticker |
| `DELETE` | `/api/watchlist/custom/{ticker}` | Remove a ticker |

---

## Authentication

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/upstox/login` | Generate OAuth login URL and redirect |
| `GET` | `/callback` | OAuth redirect handler — saves new token to `.env` |
| `GET` | `/api/upstox/token-status` | Check whether the current token is valid |
