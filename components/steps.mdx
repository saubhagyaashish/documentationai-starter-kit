## Screener Endpoints

### GET /api/indices

List all available NSE indices for screening.

**Response:**
```json
{
  "indices": ["NIFTY 50", "NIFTY BANK", "NIFTY IT", "NIFTY PHARMA", "NIFTY AUTO"]
}
```

### GET /api/screen

Scan an index and return flagged stocks (technical extremes, volume spikes).

**Query Parameters:**
- `index` (string, required) — Index to scan (e.g., "NIFTY 50")

**Response:**
```json
{
  "index_name": "NIFTY 50",
  "last_updated": "2026-05-03T10:15:30",
```

## Analysis Endpoints (LLM Pipeline)

### GET /api/analyze/stream

Stream live 13-agent analysis pipeline with progress updates via Server-Sent Events (SSE).

**Query Parameters:**
- `ticker` (string, required) — Stock ticker, e.g. `"INFY.NS"`
- `date` (string, required) — Analysis date (YYYY-MM-DD)

**SSE Event — Progress:**
```json
{
  "type": "progress",
  "agent": "Market Analyst",
  "timestamp": "2026-05-03T10:15:30"
}
```

**SSE Event — Final Result:**
```json
{
  "type": "result",
  "decision": "BUY",
  "rating": "5/5",
  "reports": {
    "Market Analyst": "Market sentiment is bullish...",
    "News Analyst": "Recent news shows strong growth...",
    "Fundamentals Analyst": "P/E ratio is attractive...",
    "Bull Researcher": "Bull case: strong tech demand...",
    "Bear Researcher": "Bear case: valuation concerns...",
    "Research Manager": "Consensus: BUY on dips...",
    "Trader": "Entry plan: buy on support...",
    "Portfolio Manager": "FINAL: BUY - risk/reward favorable"
  }
}
```

**SSE Event — Error:**
```json
{
  "type": "error",
  "message": "Ticker not found or API error"
}
```

**JavaScript/TypeScript Usage:**
```typescript
const eventSource = new EventSource(
  'http://localhost:8000/api/analyze/stream?ticker=INFY.NS&date=2026-05-03'
);
eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'progress') {
    console.log(`${data.agent} completed`);
  } else if (data.type === 'result') {
    console.log(`Decision: ${data.decision}`);
    eventSource.close();
  }
};
```

### POST /api/paper/buy

Manually enter a long position.

**Request Body:**
```json
{
  "symbol": "INFY.NS",
  "quantity": 10,
  "price": 1842.00,
  "stop_loss": 1814.00,
  "target_price": 1920.00,
  "strategy": "manual"
}
```

**Response:**
```json
{
  "success": true,
  "position_id": "INFY.NS_20260503_094700",
  "entry_price": 1842.00,
  "stop_loss": 1814.00,
  "target": 1920.00,
  "capital_remaining": 97500.00
}
```

### POST /api/paper/sell

Manually exit a position.

**Request Body:**
```json
{
  "symbol": "INFY.NS",
  "quantity": 10,
  "exit_price": 1880.00
}
```

**Response:**
```json
{
  "success": true,
  "pnl": 380.00,
  "pnl_pct": 2.06,
  "capital_returned": 18800.00,
  "total_capital": 98300.00
}
```

### GET /api/paper/history

**Query Parameters:**
- `limit` (integer, optional) — Number of trades to return (default: 50)

**Response:**
```json

      "pnl_pct": 2.06,
      "exit_reason": "target_hit",
      "strategy": "technical_signal"
    }
  ],

}
```

## Scanner Control Endpoints

### GET /api/scanner/status

Get auto-scanner status and last scan results.

**Response:**
```json
{
  "is_running": true,
  "scans_today": 12,
  "auto_trades_today": 3,
  "last_scan_time": "2026-05-03T14:55:00",
  "last_scan_results": {
    "movers_found": 8,
    "auto_buys": [
      {
        "symbol": "RELIANCE.NS",
        "quantity": 10,
        "price": 2450.50,
        "score": 0.78
      }
    ],
    "auto_sells": [
      {
        "symbol": "HDFC.NS",
        "exit_price": 2105.00,
        "pnl": 150.00
      }
    ]
  }
}
```

### POST /api/scanner/start

Resume the auto-scanner (if it was stopped).

```json
{ "success": true, "message": "Scanner resumed" }
```

### POST /api/scanner/stop

Pause the auto-scanner. Existing positions are still monitored.

```json
{ "success": true, "message": "Scanner paused. Existing positions still monitored." }
```

## Market Status Endpoints

### GET /api/market/status

**Response:**
```json
{
  "status": "OPEN",
  "is_open": true,
  "reason": "Trading hours",
  "time": "14:32:45 IST",
  "next_trading_day": "2026-05-04"
}
```

| Status | Meaning |
|---|---|
| `OPEN` | Market trading (09:30–15:20 IST) |
| `PRE_MARKET` | Before market opens (before 09:30) |
| `POST_MARKET` | After market closes (after 15:20) |
| `CLOSED` | Weekend or NSE holiday |

### GET /api/upstox/status

Check Upstox API connection and token validity.

```json
{
  "connected": true,
  "last_quote_time": "2026-05-03T14:32:00",
  "auth_token_valid": true,
  "error": null
}
```

## Error Responses

All endpoints return a standard error format on failure:

```json
{ "error": "Invalid ticker format", "status": 400 }
{ "error": "Database connection failed", "status": 500 }
```

---

## Rate Limits & Caching

| Endpoint | Caching |
|---|---|
| `/api/screen` | Cached 5 minutes |
| `/api/scanner/status` | Real-time, < 100 ms |
| `/api/paper/*` | Real-time, < 50 ms |
| `/api/analyze/stream` | No cache, SSE stream |
| `/api/predictions` | Cached 1 hour |

## Python Usage Example

```python
import requests

# Get scanner status
resp = requests.get('http://localhost:8000/api/scanner/status')
status = resp.json()
print(f"Scanner running: {status['is_running']}")
print(f"Auto trades today: {status['auto_trades_today']}")

# Get predictions
resp = requests.get('http://localhost:8000/api/predictions?limit=10')
for pred in resp.json()['predictions']:
    print(f"{pred['ticker']}: {pred['decision']} ({pred['return_pct']:.2f}%)")

# Manual buy
resp = requests.post('http://localhost:8000/api/paper/buy', json={
    "symbol": "INFY.NS",
    "quantity": 10,
    "price": 1842.00,
    "stop_loss": 1814.00,
    "target_price": 1920.00,
    "strategy": "manual"
})
print(resp.json())
```
