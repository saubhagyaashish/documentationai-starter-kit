## Overview

The auto-scanner (`signal_scanner.py`) is an autonomous trading bot that runs continuously during market hours. Every 5 minutes it fetches live prices for all NIFTY 50 stocks, filters for meaningful movers, scores their technical signals, and auto-enters or exits paper positions based on those scores.

<Callout kind="alert">
  The auto-scanner is **disabled by default**. It must be explicitly started from the dashboard or via the API. It does not run on server startup.
</Callout>

## Scan Cycle — Every 5 Minutes

<Steps>
  <Step title="Batch LTP fetch" icon="download" title-type="p">
    One API call fetches live prices for all 48 NIFTY 50 stocks — minimising Upstox rate-limit usage.
  </Step>
  <Step title="Filter movers" icon="filter" title-type="p">
    Stocks with an intraday change of less than ±0.5% are skipped. Only meaningful movers continue.
  </Step>
  <Step title="Compute signals for top 15" icon="bar-chart-2" title-type="p">
    The top 15 movers by absolute % change get full technical indicator analysis and a composite signal score.
  </Step>
  <Step title="Auto-enter on strong BUY" icon="trending-up" title-type="p">
    If a stock scores ≥ 0.65 **and** its price is moving upward, a paper BUY is entered — subject to all risk management pre-flight checks.
  </Step>
  <Step title="Auto-exit on weak signal" icon="trending-down" title-type="p">
    If an open position's stock now scores ≤ 0.35, the position is closed with exit reason `SIGNAL_WEAK`.
  </Step>
  <Step title="Check stop-loss and take-profit" icon="shield" title-type="p">
    All open positions are checked against their stop-loss and target levels using the latest batch prices.
  </Step>
  <Step title="Force-close at 15:20 IST" icon="clock" title-type="p">
    Five minutes before NSE close, all remaining open positions are force-closed with exit reason `TIME_EXIT`.
  </Step>
</Steps>

## Signal Thresholds

| Score | Direction | Action |
|---|---|---|
| ≥ 0.65 | Price moving UP | Auto-enter BUY |
| ≤ 0.35 | Holding a position | Auto-exit (SIGNAL_WEAK) |
| 0.35 – 0.65 | Any | No action |

## Scanner Configuration

| Setting | Default | Description |
|---|---|---|
| `scan_interval_seconds` | 300 | How often to run a full scan cycle |
| `min_move_pct` | 0.5 | Minimum intraday % change to qualify for scoring |
| `top_movers_count` | 15 | How many top movers to score per cycle |
| `buy_threshold` | 0.65 | Score required to trigger a BUY |
| `sell_threshold` | 0.35 | Score that triggers a SELL / exit |
| `auto_trade` | true | Whether to place trades or just report signals |

```bash
POST http://localhost:8000/api/scanner/config
{
  "scan_interval_seconds": 180,
  "buy_threshold": 0.70,
  "top_movers_count": 10
}
```

## Managing the Scanner

<Tabs>
  <Tab title="Dashboard" icon="monitor">
    1. Open the **Paper Trading** tab.
    2. Click **Start Scanner** in the Auto-Scanner card.
    3. The status indicator turns green and shows the last scan time.
    4. Click **Stop Scanner** to pause it.
  </Tab>
  <Tab title="API" icon="code">
    ```bash
    POST /api/scanner/start     # Start
    POST /api/scanner/stop      # Stop
    GET  /api/scanner/status    # Check state
    POST /api/scanner/scan-now  # Trigger immediate scan
    ```
  </Tab>
</Tabs>

## Morning Pre-Market Scanner

A separate job in `scheduler.py` (APScheduler) runs a **pre-market screen at 9:00 AM IST** every trading day:

- Fetches overnight news and global market cues
- Screens all NIFTY 50 stocks for fundamental and news-based flags
- Generates a morning watchlist of stocks worth monitoring that day
- Results appear in the **Screener** tab when you open the dashboard

The morning scanner runs independently of the intraday auto-scanner and does not place any trades.
