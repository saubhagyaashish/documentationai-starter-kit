## Overview

The paper trading engine (`paper_trader.py`) simulates real stock trades without using actual money. Every entry and exit goes through pre-flight risk checks, slippage simulation, and automatic stop-loss / take-profit monitoring.

<Callout kind="info">
  Paper trading is entirely simulated. No orders are sent to any broker or exchange. It is designed to let you test strategies and build confidence before risking real capital.
</Callout>

## Entering a Trade — Pre-flight Checks

When a BUY signal fires (manually or via the auto-scanner), the engine runs these checks in order:

<Steps>
  <Step title="Daily loss limit check" icon="shield" title-type="p">
    If today's P&L has already reached **−2% of total capital**, all new entries are blocked for the rest of the trading day.
  </Step>
  <Step title="Circuit breaker check" icon="zap" title-type="p">
    If 3 consecutive trades have been losses, a **30-minute cool-down** is enforced before new positions can be entered.
  </Step>
  <Step title="Max positions check" icon="layers" title-type="p">
    A maximum of **5 concurrent open positions** is allowed. A full portfolio rejects new entries.
  </Step>
  <Step title="Duplicate position check" icon="copy" title-type="p">
    An existing open position in the same stock prevents a second entry.
  </Step>
  <Step title="Position size check" icon="percent" title-type="p">
    Each trade is sized at **5% of total capital**. If that amount exceeds available capital, the trade is rejected.
  </Step>
  <Step title="Slippage applied and position saved" icon="save" title-type="p">
    A **+0.05% slippage** is added to the entry price, the position is created, capital is reserved, and the trade is written to SQLite.
  </Step>
</Steps>

## Exit Triggers

Positions are closed by one of six triggers:

| Trigger | Condition | How It Fires |
|---|---|---|
| **Stop Loss** | Price ≤ entry − stop distance | Automatic, checked each scanner cycle |
| **Target** | Price ≥ take-profit level | Automatic, checked each scanner cycle |
| **Trailing Stop** | Price retraces from peak by the trailing distance | Automatic, adjusted upward as price rises |
| **Time Exit** | Clock reaches **15:20 IST** | Automatic, enforced by the scheduler |
| **Signal Weak** | Signal score drops to ≤ 0.35 | Automatic, evaluated each scanner cycle |
| **Manual** | User clicks Exit in the dashboard | Immediate |

A **−0.05% slippage** is applied to all exit prices.

## Risk Management Rules

| Rule | Value | Rationale |
|---|---|---|
| Max daily loss | −2% of capital | Prevents catastrophic drawdown days |
| Max concurrent positions | 5 | Ensures diversification |
| Position size per trade | 5% of capital | Eliminates single-stock concentration |
| Stop-loss requirement | Mandatory on every entry | No naked trades |
| Circuit breaker | 3 consecutive losses → 30-min pause | Forces a cool-down after losing streaks |
| Time-based exit | Force-close at 15:20 IST | Eliminates overnight gap risk |
| Entry / exit slippage | ±0.05% | Simulates realistic fill prices |

## Portfolio Dashboard

The Paper Trading UI shows:

- **Open Positions** — current holdings with live P&L, entry price, stop-loss, and target
- **Available Capital** — capital not currently deployed
- **Today's P&L** — cumulative intraday profit/loss in ₹ and %
- **Total P&L** — lifetime paper trading P&L since inception
- **Win Rate** — percentage of closed trades that were profitable
- **Trade History** — all closed trades with entry/exit details and exit reason

## State Persistence

The engine survives server restarts. On startup it reconstructs state from SQLite:

1. **Open positions** — rows in `paper_trades` where `exit_time IS NULL`
2. **Daily stats** — from today's row in `paper_portfolio`
3. **Circuit breaker** — from the last 3 closed trades' outcomes
4. **Available capital** — total capital minus reserved capital across open positions

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/paper/portfolio` | Full state: positions, capital, stats |
| `POST` | `/api/paper/buy` | Enter a paper trade |
| `POST` | `/api/paper/sell` | Exit a specific position |
| `GET` | `/api/paper/history` | All closed trades |
| `GET` | `/api/paper/performance` | Win rate, P&L breakdown |

```bash
POST http://localhost:8000/api/paper/buy
{
  "symbol": "RELIANCE",
  "instrument_key": "NSE_EQ|INE002A01018",
  "stop_loss": 2890.00,
  "target_price": 3050.00,
  "signal_score": 0.73
}

# Response
{
  "status": "success",
  "trade_id": 42,
  "entry_price": 2946.97,
  "quantity": 5,
  "capital_reserved": 14734.85
}
```
