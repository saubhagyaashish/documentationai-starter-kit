## What Is TradeBotX?

TradeBotX is a full-stack trading intelligence platform built for the **Indian stock market (NSE)**. It combines a 13-agent AI pipeline powered by LLMs with real-time market data from Upstox, 9 deterministic technical indicators, and a fully automated paper trading engine — all accessible through a modern React dashboard.

Think of it as your personal AI trading desk: it screens stocks, debates bull vs. bear cases using multiple AI agents, computes technical signals every 5 minutes, and auto-trades in paper mode with proper risk management — without risking real money.

<Callout kind="info">
  TradeBotX currently operates in **paper trading mode only**. No real orders are placed on any exchange. Phase 14 of the roadmap introduces live Upstox order execution once a verified 3-month track record is established.
</Callout>

## System Architecture

TradeBotX is built as five interconnected layers:

```
┌─────────────────────────────────────────────────────────┐
│  DASHBOARD (React 19 + TypeScript at localhost:5173)    │
│  Views: Dashboard, Screener, Analysis, Paper Trading,   │
│         Watchlist, Predictions, Results                 │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  API SERVER (FastAPI at localhost:8000)                  │
│  ├─ /api/screen           screener + flagged stocks     │
│  ├─ /api/analyze/stream   13-agent SSE pipeline         │
│  ├─ /api/paper/*          paper trading endpoints       │
│  ├─ /api/scanner/*        scanner control + status      │
│  └─ /api/predictions      accuracy tracking             │
└──────────────────┬──────────────────────────────────────┘
                   │
        ┌──────────┴────────────┐
        │                       │
┌───────▼────────┐    ┌────────▼──────────┐
│ FAST LAYER     │    │ LLM PIPELINE      │
│ (Real-time)    │    │ (Deep research)   │
│ • RSI, MACD    │    │ • 13 agents       │
│ • EMA, VWAP    │    │ • News sentiment  │
│ • Bollinger    │    │ • Fundamentals    │
│ • Stochastic   │    │ • Risk debate     │
│ • ATR, Volume  │    │ (2–5 min/stock)   │
│ (< 1 sec)      │    │                   │
└───────┬────────┘    └────────┬──────────┘
        └──────────┬───────────┘
                   │
        ┌──────────▼──────────────┐
        │  PAPER TRADER + SCANNER │
        │  Virtual positions      │
        │  Risk checks (2% DL)    │
        │  SL/TP/trailing stops   │
        │  State in SQLite        │
        │  Auto-scan every 5 min  │
        └─────────────────────────┘
```

## Why TradeBotX?

| Problem | TradeBotX Solution |
|---|---|
| Manual stock research takes hours | 13 AI agents analyse a stock in ~2–5 minutes |
| Emotional trading decisions | Deterministic composite signal scores (0.0–1.0) |
| Missing intraday moves | Auto-scanner monitors NIFTY 50 every 5 minutes |
| No way to test strategies | Paper trading with full risk management and real prices |
| Expensive trading terminals | Free, self-hosted, open-source |
| Slow intraday signals from LLM | Fast technical layer — 50 stocks scored in under 1 second |

## The React Dashboard

The frontend (`localhost:5173`) has seven views:

| View | Purpose |
|---|---|
| **Dashboard** | Real-time market status, daily loss bar, win/loss pie chart, active positions table |
| **Screener** | NSE index stock scanner — flags RSI extremes, volume spikes, price action |
| **Analysis** | Live 13-agent pipeline progress (SSE) and final decision with agent reports |
| **Paper Trading** | Live positions, entry/exit history, manual buy/sell, P&L tracking |
| **Watchlist** | Custom ticker list, live prices, quick analysis launcher |
| **Predictions** | AI decision accuracy by rating, win rate trends, per-stock statistics |
| **Results** | Historical analysis browser with expandable agent reports |

## LLM Pipeline Phases

```
Phase 1 — Analyst Team (run in parallel)
  Market Analyst, Social Media Analyst, News Analyst,
  Fundamentals Analyst, India Macro Analyst

Phase 2 — Researcher Team (debate rounds)
  Bull Researcher ↔ Bear Researcher → Research Manager

Phase 3 — Trader
  Composes all analyst reports into an investment plan

Phase 4 — Risk Management Team (debate rounds)
  Aggressive / Conservative / Neutral Debaters → Portfolio Manager
```
