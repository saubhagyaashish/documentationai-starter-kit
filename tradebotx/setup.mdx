## Prerequisites

Before you begin, make sure you have the following:

| Requirement | Version | Notes |
|---|---|---|
| **Python** | 3.12+ | Earlier versions are untested |
| **Node.js** | 18+ | Required for the React frontend |
| **Upstox Developer Account** | — | Free account at [developer.upstox.com](https://developer.upstox.com) |
| **OpenAI API Key** | — | Required for the 13-agent AI pipeline |

<Callout kind="tip">
  An Upstox trading account is required to use the live API. You can use `UPSTOX_MODE=sandbox` in your `.env` for development without a live account.
</Callout>

## Installation

<Steps>
  <Step title="Clone the repository" icon="download" title-type="p">
    ```bash
    git clone https://github.com/your-org/tradebotx.git
    cd tradebotx
    ```
  </Step>

  <Step title="Create a Python virtual environment" icon="box" title-type="p">
    ```bash
    python -m venv venv

    # Activate on Windows
    .\venv\Scripts\activate

    # Activate on macOS / Linux
    source venv/bin/activate
    ```
  </Step>

  <Step title="Install Python dependencies" icon="package" title-type="p">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>

  <Step title="Configure environment variables" icon="settings" title-type="p">
    ```bash
    cp .env.example .env
    ```

    Then open `.env` and fill in your API keys (see the [Environment Variables](#environment-variables) section below).
  </Step>

  <Step title="Install frontend dependencies" icon="layers" title-type="p">
    ```bash
    cd frontend
    npm install
    cd ..
    ```
  </Step>
</Steps>

## Environment Variables

Open `.env` and configure these values:

```env
# ── LLM Provider ─────────────────────────────────────────
OPENAI_API_KEY=sk-proj-...          # Your OpenAI API key

# ── Upstox API ────────────────────────────────────────────
UPSTOX_ACCESS_TOKEN=eyJ0eX...       # JWT token — refreshed daily via OAuth
UPSTOX_API_KEY=9e6b9529-...         # Your Upstox app API key
UPSTOX_API_SECRET=zfzQ8g...         # Your Upstox app API secret
UPSTOX_REDIRECT_URI=http://localhost:8000/callback
UPSTOX_MODE=live                    # "live" for real data, "sandbox" for development
```

<Callout kind="alert">
  Leave `UPSTOX_ACCESS_TOKEN` blank on first run. The OAuth flow (step below) will populate it automatically after you log in.
</Callout>

### Where to Get Your Upstox Keys

1. Go to [developer.upstox.com](https://developer.upstox.com) and create a new app.
2. Set the redirect URI to `http://localhost:8000/callback`.
3. Copy the **API Key** and **API Secret** into your `.env`.

## Running TradeBotX

Open two terminal windows:

<Tabs>
  <Tab title="Terminal 1 — Backend">
    ```bash
    # Activate virtual environment first
    .\venv\Scripts\activate   # Windows
    source venv/bin/activate  # macOS / Linux

    # Start the FastAPI backend
    python api_server.py
    ```

    The backend starts on **http://localhost:8000**.
  </Tab>

  <Tab title="Terminal 2 — Frontend">
    ```bash
    cd frontend
    npm run dev
    ```

    The frontend starts on **http://localhost:5173**.
  </Tab>
</Tabs>

Then open **http://localhost:5173** in your browser.

## Daily Token Refresh

Upstox access tokens expire every day at **midnight IST**. The refresh flow takes under 30 seconds:

<Steps>
  <Step title="Open the login URL" icon="external-link" title-type="p">
    Navigate to **http://localhost:8000/api/upstox/login** in your browser.
  </Step>

  <Step title="Log in to Upstox" icon="lock" title-type="p">
    You'll be redirected to Upstox's login page. Enter your credentials and click **Authorize**.
  </Step>

  <Step title="Token saved automatically" icon="check-circle" title-type="p">
    Upstox redirects you back to the callback URL. TradeBotX saves the new token to `.env` automatically. No restart needed.
  </Step>
</Steps>

## Verifying the Setup

After both services are running and the token is set, verify everything is working:

```bash
# Check Upstox connection and token validity
curl http://localhost:8000/api/upstox/ltp/batch?index=NIFTY50

# Should return live prices for all NIFTY 50 stocks
```

If the backend is running but returns `401`, your token needs to be refreshed (see Daily Token Refresh above).

## Running the AI Pipeline Only (No UI)

You can run the 13-agent pipeline standalone from the terminal without starting the frontend:

```bash
python main.py --ticker RELIANCE --date 2025-01-15
```

Results are printed to stdout and saved to the `predictions` SQLite table.

## Common Issues

<Callout kind="alert" collapsed="true">
  **`ModuleNotFoundError` on startup** — Your virtual environment is not activated. Run `.\venv\Scripts\activate` (Windows) or `source venv/bin/activate` (macOS/Linux) before running `python api_server.py`.
</Callout>

<Callout kind="alert" collapsed="true">
  **`404 Not Found` for a stock** — The instrument ISIN for that stock has changed due to a corporate action. Update the mapping in `upstox_client.py` with the current ISIN from nseindia.com.
</Callout>

<Callout kind="alert" collapsed="true">
  **Intraday signal scores are always 0.5** — The intraday candle endpoint returns `404` when the market is closed (weekends and holidays). This is expected behaviour. The engine falls back to SMA-200 as a VWAP substitute.
</Callout>

<Callout kind="alert" collapsed="true">
  **`RateLimitError` from OpenAI** — The 13-agent pipeline makes multiple LLM calls in sequence. If you're on a free-tier OpenAI account, you may hit rate limits. Add a delay in `default_config.py` or upgrade your OpenAI plan.
</Callout>
