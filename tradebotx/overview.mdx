## What Is TradeBotX?

TradeBotX is a full-stack trading intelligence platform built for the **Indian stock market (NSE)**. It combines a 13-agent AI pipeline powered by LLMs (GPT-4 / Claude) with real-time market data from Upstox, automated technical analysis, and a simulated paper trading engine — all accessible through a modern React dashboard.

Think of it as your personal AI trading desk: it screens stocks, debates bull vs. bear cases using multiple AI agents, computes technical signals, and can auto-trade in paper mode — without risking real money.

<Callout kind="info">
  TradeBotX is designed for **paper trading only**. No real orders are placed on any exchange. It is a research and strategy-testing tool.
</Callout>

## Key Capabilities

| Capability | Description |
|---|---|
| **13-Agent AI Pipeline** | LangGraph multi-agent system producing BUY / SELL / HOLD decisions |
| **Live Market Data** | Real-time LTP, OHLCV candles, and WebSocket tick feed via Upstox V2/V3 API |
| **Technical Indicator Engine** | RSI, MACD, VWAP, Bollinger Bands, EMA, Volume Surge — computed locally |
| **Paper Trading Engine** | Simulated trades with stop-loss, take-profit, trailing stops, and time-based exits |
| **Auto-Scanner** | Scheduled bot that screens NIFTY 50 every 5 minutes and auto-enters/exits positions |
| **Prediction Tracker** | SQLite-backed accuracy tracking for all AI decisions |
| **React Dashboard** | 6-tab UI: Screener, Analysis, Paper Trading, Watchlist, Predictions, Results |
